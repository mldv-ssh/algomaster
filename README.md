# AlgoMaster

Cours interactif d'algorithmique, en partant de zéro : leçons avec exécution pas à pas, quiz corrigés instantanément, flashcards, examen blanc et atelier de pseudo-code corrigé automatiquement.

Tout tient dans un seul fichier `index.html`, sans serveur ni dépendance. Ouvrir le fichier dans un navigateur suffit ; le site est aussi servi par GitHub Pages.

La progression est enregistrée dans le navigateur de chaque visiteur (localStorage).
