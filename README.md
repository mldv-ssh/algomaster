## ✨ Fonctionnalités

| | Module | Ce qu'il fait |
|---|---|---|
| 📖 | **Leçons** | Chaque notion expliquée avec une exécution **pas à pas** de l'algorithme |
| ✅ | **Quiz** | Questions corrigées **instantanément** |
| 🃏 | **Flashcards** | Révision rapide des définitions et concepts clés |
| 📝 | **Examen blanc** | Mise en situation complète pour tester ses acquis |
| 💻 | **Atelier pseudo-code** | Écris ton algorithme, il est **corrigé automatiquement** |
| 💾 | **Progression** | Sauvegardée dans ton navigateur, sans compte |

## 🚀 Utilisation

**En ligne** : ouvre la [version GitHub Pages](https://UTILISATEUR.github.io/AlgoMaster/).

**En local** : aucune installation.

```bash
git clone https://github.com/UTILISATEUR/AlgoMaster.git
cd AlgoMaster
```

Puis ouvre `index.html` dans ton navigateur. C'est tout.

## 🛠️ Sous le capot

- **Un seul fichier** `index.html` : HTML, CSS et JavaScript réunis
- **Aucun serveur, aucune dépendance**, aucun build
- **`localStorage`** pour enregistrer la progression de chaque visiteur
- Hébergé gratuitement via **GitHub Pages**

> ℹ️ La progression reste sur l'appareil et le navigateur utilisés. Vider les données du site la réinitialise.
